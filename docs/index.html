The Markdown reader for AI-generated documents

Long reports, plans and tables rendered the way Claude shows them, with tools to review, compare and work with them. Read it, comment on it, hand it back.

Download for Windows View on GitHub

Windows 10 and 11. No admin rights needed. The installer is unsigned, so SmartScreen may ask you to click “More info” then “Run anyway”.

Built around how you actually use AI output

Most Markdown apps are editors. MD Reader starts from reading, then adds the steps that come next.

Review mode

Comment on the text, send one clean prompt

Select any passage and add a comment. When you are done, copy every comment as a single structured revision request, with the quote and section for each one.

  • Highlights stay on the page
  • Comments are saved per file on your PC
  • One click copies and opens Claude
What changed

See exactly what a rewrite touched

MD Reader remembers the last version you read. When the file changes, a bar shows what was added or removed, in green and red, so you never reread a whole document to find one edit.

  • Works live while the file is open
  • Compares at the block level: paragraphs, tables, lists
Tables

Sort, filter, export, chart

Click a header to sort. Filter rows, copy for Excel, save as CSV, or turn a table into a chart in one click.

Tasks

Checkboxes that write back

Tick a task and the file updates. Each section shows its progress, ideal for plan files.

Claude

Copy or ask, section by section

Hover a heading to copy that section with its context, or send a section, table or selection to Claude.

Size

Token estimate

Know roughly how large a document is before you paste it into a conversation.

Reading

Read aloud and focus mode

Listen with the current block highlighted, or dim everything except what you hover.

Editor

Live preview editing

Edit with a formatting toolbar and a live preview, with tabs, export to PDF and HTML, and recent files.

Editor

Edit side by side

Toggle the editor for a split view with a live preview that follows your scrolling. Lists continue as you type, and shortcuts cover bold, italic and links.

How it is built

A desktop app with no server and no account. Your files never leave your computer unless you choose to copy something into Claude.
